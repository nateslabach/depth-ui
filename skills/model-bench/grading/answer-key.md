1. Save the private key **outside** this repo, recommended path:
   `~/proctor/model-bench/answer-key.md`

3. Grade only after all legs for that model have finished.

Local override filename if you insist on keeping a copy near the skill (still gitignored):

`skills/model-bench/grading/answer-key.local.md`
